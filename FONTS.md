# Fonts

All typefaces are bundled as latin-subset `.woff2` files in `v3/fonts/` and are
embedded into `index.html` as data URIs, so the page makes no network requests.

| Family | Weights | Files | Licence |
| --- | --- | --- | --- |
| Bricolage Grotesque | 300, 500 | `display-normal-300.woff2`, `display-normal-500.woff2` | SIL Open Font License 1.1 |
| Instrument Serif | 400 roman + italic | `serif-normal-400.woff2`, `serif-italic-400.woff2` | SIL Open Font License 1.1 |
| Inter Tight | 300, 400, 500 | `sans-normal-300/400/500.woff2` | SIL Open Font License 1.1 |

The OFL permits bundling and redistribution in a document or application, including
commercial use, as long as the fonts are not sold on their own. If you fork this and
change the typefaces, keep these files or replace them with your own licensed copies.

Older editions use different families (v2: Bodoni Moda / Inter Tight / IBM Plex Mono;
v1: Anuphan with Thai + latin subsets) — same OFL terms, files live in `v2/fonts/`
and `v1/assets/fonts/`.
